# `.duy` 行式格式规范（摘要）

本文件描述 `duy_mini.exe` 实现的格式。它是**本执行器所遵循的规范**——不是某个更大系统的完整规格，但足以让第三方校验「另一份实现是否符合同一格式」。

## 一、文件结构

一个 `.duy` 文件可含多个组件：

```
文件  = 组件*
组件  = 头声明 步行体
```

## 二、头声明

| 声明 | 次数 | 含义 |
|---|---|---|
| `prim_key <NAME>` | 1 | 组件名（大写）；同一文件内**不得重复** |
| `prim_scope <scope>` | 0..1 | `per_unit` / `per_gen`，缺省 `per_unit`；本执行器解析并保存，**语义未实现**（一律按 `per_unit` 执行） |
| `prim_phase <phase>` | 0..1 | 为 `per_gen` 生命周期预留（如 `pre_rules`）；本执行器仅记录，**语义未实现** |
| `prim_ret <槽>` | 0..1 | 回执：`_局部槽` 或 `$形参`；缺省无回执 |
| `prim_param <名> <类型>` | 0..* | 形参，**声明序 = 调用绑定序** |

## 三、步行

每行一步：

```
算子名 字段=值 字段=值 …
```

**字段值三型**：

| 形式 | 类型 | 例 |
|---|---|---|
| `$name` | 形参引用 | `out='$var'` |
| `_name` | 组件内局部槽 | `out='_tmp'` |
| 裸数字 | 数值字面量 | `val=10` `decay=1` |
| `'文本'` | 字符串字面量 | `a='ABC'` `src='_i+1'` |

⚠ **引号决定类型**：`val=10` 是数值，`val='10'` 是字符串。`n` 类字段必须写裸数字。

## 四、嵌套

无缩进语义，用关键字开合：

```
while until='_i>=3'
body_open
  eval_expr src='_i+1' out='_i'
body_close
```

`body_open` 挂在**上一行步**上；只有 `while` / `if` 允许带体。

## 五、注释

`#` 到行尾。**引号内的 `#` 不是注释**：

```
str_cat a='a#b' out_concept='r'    # ← 'a#b' 完整保留；这半句是注释
```

## 六、参数类型

| 短式 | 全称（等价） | 值域 |
|---|---|---|
| `s` | `str` | 文本（数据或槽名） |
| `n` | `num` | 数值 |
| `a` | `arr` | 文本数组 |
| `e` | `expr` | 表达式文本（求值） |

## 七、表达式子语言

数值域，出现在 `src` / `cond` / `until` / `start` / `len` / `n` 等 `e` 类字段：

- 常量、`$变量`、`_局部槽`
- 算术 `+ - * / % ^`（`^` 右结合，优先级最高）
- 比较 `> < >= <= == !=`（返回 `1` / `0`）
- `min` `max` `neg`
- `sqrt` `abs` `exp` `log` `sin` `cos` `floor`

**无位运算**、**无字符串运算**、**无逻辑运算符**（用 `(a>0)*(b>0)` 代替 `and`）。

## 八、边界语义（本执行器定义）

| 情形 | 结果 |
|---|---|
| 取模 `%` | `fmod`：保被除数符号（`-7 % 3 = -1`） |
| 除零 | `0`（不报错） |
| `while` | **do-while**：先跑体，再判 `until`（`>0` 停）⇒ 空/零边界需前置 `if` 守卫 |
| `if` | 条件 `>0` 执行体；不执行体时无副作用 |
| `stop` | 在 `while` 体内 = 退出该循环；在 `if` 体内 = 传给最近的 `while`；组件级 = 中止整条序列 |
| 文本 | **UTF-8 字节序列**（中文 3 字节/字）；所有文本算子按字节工作 |
| 空文本记忆 | **不落库**（空结果 = 概念缺失 + 回执 `0`） |
| `str_slice` 负 `start` / 负 `len` | 空串 |
| `str_slice` `len` 超界 | 截断到可用长度 |
| `str_ord` 空串 | `0` |
| `str_chr` 码 `<0` 或 `>255` | 归 `0`（不是取模） |
| `str_find` 未命中 | `-1` |
| `str_num` 非整数 | `%.6g` |

## 九、装载期拒绝

以下情况**装载即报错**，不静默容忍：

- 未知算子（点名报出）
- 重复 `prim_key`
- `body_open` 未闭合
- 字段形态非法 / 参数类型未知
- `while` 的 `until` 必须引用循环体内某步的 `out`（停止条件挂不到体产出的量上 = 装载拒绝）

## 十、回执约定

`prim_ret` 指向的槽必须由某个**写类步**的 `out` 写入（写类 = 产生记忆副作用或写槽回报的算子）。纯只读步的 `out` 不接受作为回执。
